# CineScope — Інформаційний портал про кіно

Вебзастосунок для перегляду та адміністрування каталогу фільмів, розроблений на PHP-фреймворку Laravel (MVC).

## Реалізований функціонал:
- Авторизація та реєстрація користувачів
- Перегляд каталогу фільмів та детальної інформації
- Групування та фільтрація кінострічок за жанрами
- Оновлення матеріалів порталу (адміністративна панель)
